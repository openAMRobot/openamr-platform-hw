# TZBOT wireless charger

The OpenAMRobot 2.0 and release 001 charging path is the TZBOT WCM-500-24 (output 28.4 V), register entries CHARGING and SHARED-BASE. Its datasheet belongs in this folder.

The WCM-300 is only the existing unit on the release 001 robot and is not the design. Its manual was removed on 22 Oct 2026 and remains in the Git history of this repository.
